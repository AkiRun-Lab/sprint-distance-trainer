# SDT ユーザーマニュアル

**バージョン：v1.1.0　最終更新：2026-05-11**

---

## 1. はじめに

SDT（Sprint & Distance Trainer）は、100m から 1500m を対象とした短距離・中距離ランナー向けの AI トレーニング計画生成ツールです。  
Google Gemini を活用し、ランナーの現状・目標・環境条件をもとに、科学的根拠に基づいた週次トレーニング計画を自動生成します。  
オプションとして走行動画のフォーム診断を実施し、診断結果をそのまま計画に組み込むことができます。

---

## 2. 使い方の流れ

```
STEP 1 基本情報入力
  ↓
STEP 2 フォーム診断（任意・スキップ可）
  ↓
STEP 3 トレーニング計画の生成・ダウンロード
```

---

## 3. STEP 1 — 基本情報の入力

### 入力項目

| 項目 | 内容 | 備考 |
|------|------|------|
| 目標距離 | 100m / 200m / 400m / 800m / 1500m | 選択式 |
| ニックネーム | 任意の呼び名 | 計画書に表示されます |
| 年齢 | 10〜100 歳 | |
| 性別 | 男性 / 女性 / その他 | |
| 週練習日数 | 2〜7 日 | |
| 現在のベストタイム | 距離ごとのフォーマットで入力 | ※フォーマット例を参照 |
| 目標タイム | 同上 | |
| 目標レース日 | カレンダーで選択 | 翌日以降 |
| トラック（競技場）が使える | チェックボックス | |
| ウェイトジムが使える | チェックボックス | |
| 要望・注意事項 | 自由記述（任意） | 故障・希望・複数種目など |

### タイム入力フォーマット

| 距離 | フォーマット | 例 |
|------|------------|-----|
| 100m | 秒（小数1位） | 12.5 |
| 200m | 秒（小数1位） | 25.0 |
| 400m | 秒（小数1位） | 55.0 |
| 800m | 分:秒.小数1位 | 2:10.5 |
| 1500m | 分:秒.小数1位 | 4:30.5 |

### 「次へ」ボタン

ニックネーム・現在のベスト・目標タイムがすべて入力済みであることを確認してから押してください。

---

## 4. STEP 2 — フォーム診断（任意）

このステップはスキップできます。スキップした場合でもトレーニング計画は生成できます。

### 診断の手順

1. 走っている動画をアップロードする（MP4 / MOV / AVI / WEBM、200MB 以下）
2. 画面上で動画が再生されることを確認する
3. 「距離・気になる点など（任意）」に状況を入力する（任意）
4. 「フォームを診断する」ボタンを押す
5. 診断完了後、結果を確認する
6. 「この診断結果をトレーニング計画に反映する」にチェックを入れて「計画を作成する →」へ進む

### コンテキスト入力例

- 1000m×5インターバルの5本目後半です。ペースは3分30秒/kmです。
- 100m走のレース動画です。6コースの黄色いランシャツの選手のフォームを診断してください。

### 診断所要時間

アップロード後、AI 解析に 1〜2 分かかります。

### 注意事項

- フォーム診断は **1日3回まで** です。
- 制限に達した場合はスキップして計画作成のみ行うことができます。
- 動画は解析完了後、サーバーから自動削除されます。

---

## 5. STEP 3 — トレーニング計画の生成

### 計画概要の確認

生成前に以下の情報がカード形式で表示されます。

- 目標距離 / 目標タイム / 計画期間 / 現在のベスト / 週練習日数 / フォーム診断の有無

### 計画の生成

「トレーニング計画を生成する」ボタンを押すと、Gemini が計画を作成します（約 60 秒）。

**制限：1日3回まで。** 上限に達した場合は翌日にリロードすると利用可能になります。

### 計画の内容

生成された計画は以下の構成です。

- コーチからの挨拶・現状評価
- 基本情報まとめ
- フェーズ構成（GPP → SPP → 競技期 など）
- 週次スケジュール（曜日ごとのメニュー表）
- 注意事項
- 激励メッセージ

フォーム診断を反映した場合は、診断で指摘されたドリル・筋力トレーニング・モビリティ・プライオメトリクス・コアトレーニングが週次スケジュール内に組み込まれます。

### ダウンロード

「計画をダウンロード（Markdown）」ボタンで `.md` ファイルをダウンロードできます。  
スマートフォンで開いた場合も文字化けしないよう UTF-8 BOM 形式で出力されます。

### 最初からやり直す

「最初からやり直す」ボタンで STEP 1 からリセットできます。

---

## 6. 管理者モード

サイドバーの「管理者パスワード」入力欄にパスワードを入力してログインすると、1日の利用回数制限が解除されます。

ログアウトするには「ログアウト」ボタンを押してください。

## 7. よくある質問

**Q. ブラウザを再読み込みすると使用回数はリセットされますか？**  
A. リセットされません。使用回数は Cookie に保存され、翌日（日付が変わったとき）に自動リセットされます。

**Q. スマートフォンからも使えますか？**  
A. 使えます。レスポンシブデザインに対応しており、動画のアップロードやダウンロードも可能です。

**Q. 動画はどのくらいの長さのものが適していますか？**  
A. 5〜30秒程度の動画が最適です。長すぎるとアップロード・処理に時間がかかります。

**Q. フォーム診断をせずに計画を作成できますか？**  
A. できます。STEP 2 で「スキップして計画を作成する」を押してください。

**Q. 計画の週数はどうやって決まりますか？**  
A. 目標レース日までの週数を基準に、距離ごとの最小週数・最大週数の範囲内で自動調整されます。

| 距離 | 最小週数 | 最大週数 |
|------|--------|--------|
| 100m | 8週 | 12週 |
| 200m | 8週 | 12週 |
| 400m | 10週 | 16週 |
| 800m | 10週 | 16週 |
| 1500m | 12週 | 16週 |
